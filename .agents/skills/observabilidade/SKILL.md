Implemente instrumentação Prometheus, logs JSON via Alloy/Loki, provisionamento de Grafana e alertas; sem alta cardinalidade por run id.

4. Faça handoff explícito ao próximo papel; sinalize gaps e testes pendentes, não invente execução.
